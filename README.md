# 💻 Dev Simulator — Симулятор жизни программиста

Небольшой текстовый квест о нелегких буднях студента-айтишника. Управляй уровнем энергии, выживай на парах, принимай сложные решения и постарайся не уснуть лицом на клавиатуре до конца дня.

### 🚀 [▶️ ЗАПУСТИТЬ ИГРУ В БРАУЗЕРЕ]([https://github.io](https://uarikwork-boop.github.io/My_Pet_Project/))

---

### 📂 Что внутри проекта
* **`dev-simulator/index.html`** — веб-версия игры с визуализацией шкалы энергии.
* **`dev-simulator/game.py`** — консольный движок на Python.
* **`dev-simulator/story.json`** — база сцен, диалогов и концовок (пополняется ежедневно).

### 🛠 Как запустить локально (Python)
Если хочется поиграть прямо в терминале:
```bash
cd dev-simulator
python game.py
```
