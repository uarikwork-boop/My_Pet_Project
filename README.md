### 📂 Структура
* **`dev-simulator/index.html`** — веб-версия со шкалой энергии.
* **`dev-simulator/game.py`** — консольный Python-движок.
* **`dev-simulator/story.json`** — сюжетные сцены и концовки.

### 🛠 Запуск консольной версии
```bash
cd dev-simulator
python game.py
```
